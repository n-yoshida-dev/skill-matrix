# skill-matrix

ロードマップをマスタとして、投稿した学習ログを AI が読み取り、分野 × 詳細項目の理解度マトリクスと学習スケジュールを更新する学習管理アプリ。

チェックボックスを自分で付けるのではなく、「今日やったこと・理解したこと」をテキストで書くだけで、
理解度が升目の色の濃さとして可視化される。

## 状態

設計中。まだ実装はない。

```bash
cd frontend

cd backend
go run ./...
```

## ドキュメント

- 開発ドキュメント（AI 向け）：`PLAN.md` / `SPEC.md` / `TODO.md` / `KNOWLEDGE.md` / `HANDOFF.md`
- 設計の解説（人間向け）：`docs/`
